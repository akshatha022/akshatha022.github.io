# Akshatha B S — Portfolio

A responsive, single-page developer portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio content and structure
- `style.css` — responsive design and animations
- `script.js` — theme switcher, mobile navigation and reveal animations
- `resume.pdf` — add your latest resume here before deployment

## Before publishing

1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your real email.
3. Replace the LinkedIn placeholder URL with your LinkedIn profile.
4. Add your latest resume as `resume.pdf`.
5. Add any missing project/demo URLs.
6. Review all wording and dates.

## Run locally

You can simply double-click `index.html`, or use VS Code Live Server.

## Deploy

This is a static site, so it can be deployed through GitHub Pages, Netlify, Vercel, or another static hosting service.
